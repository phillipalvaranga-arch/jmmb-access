# JMMB Access (shortcut)

A personal, installable shortcut that opens [JMMB](https://jm.jmmb.com/)'s official website, Moneyline sign-in, and official app listings.

**This is not a JMMB app.** It does not collect usernames, passwords, PINs, account numbers, or one-time passcodes. It does not embed or proxy JMMB's login. Every action opens an official JMMB page or official app store listing in a new tab.

Live: https://phillipalvaranga-arch.github.io/jmmb-access/

Links and contact details were checked on JMMB's official Jamaica website on November 16, 2026.
